This file is a truthful application draft, not a submitted application. Public

## Repository eligibility (500 characters maximum)

Codex Goal Supervisor is an Apache-2.0 Codex plugin for keeping long-running
coding work aligned while minimizing process overhead. It provides explicit
North Star and Goal contracts, quiet progress/convergence observation, bounded
recovery after context compaction, machine-verifiable completion, and optional
role, audit, and cleanup tools. The project is actively maintained across
macOS, Windows, and Linux and ships a cross-platform regression suite.

## API credits use (500 characters maximum)

API credits would fund reproducible evaluations comparing unassisted Codex
against Goal Supervisor on long, multi-stage software tasks. We would measure
time to valid completion, rework, user interventions, false-positive warnings,
context-recovery accuracy, and final regression quality. Results and fixtures
would be published so contributors can tune interventions for net execution
benefit rather than adding governance overhead.
