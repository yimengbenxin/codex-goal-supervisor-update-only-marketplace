# Security Policy

Codex Goal Supervisor is an execution-alignment tool, not a security sandbox or
authorization boundary.

## Reporting a Vulnerability

For a security-sensitive report, use GitHub's private vulnerability reporting
for this repository. Do not include credentials, private source code, prompts,
or customer data in a public issue.

Use public GitHub issues for non-sensitive correctness and compatibility bugs.
Include the plugin version, platform, command, expected behavior, and a minimal
redacted reproduction.

## Supported Version

Only the latest published release receives fixes. Feedback delivery is disabled
by default and requires explicit project-level consent.
